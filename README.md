# OverTheWire Website Redesign

A modern, responsive redesign of the [OverTheWire](https://overthewire.org/) wargames website, built with [Astro](https://astro.build/) and [Tailwind CSS](https://tailwindcss.com/).

## 🚀 Features

- **Modern UI/UX**: A fresh look with a dark-themed aesthetic suitable for hackers.
- **Responsive Design**: Fully functional on desktop, tablet, and mobile devices.
- **Enhanced Code Blocks**: Syntax highlighting and "Copy to Clipboard" functionality for easier interaction with wargame levels.
- **Improved Navigation**: Sidebar navigation for levels and games, with next/previous buttons for seamless progression.
- **WeChall Integration**: Instructions and snippets for integrating with the WeChall scoreboard.

## 🛠️ Tech Stack

- **Framework**: [Astro](https://astro.build/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Components**: React (for interactive elements), Astro components
- **Icons**: [Lucide React](https://lucide.dev/)
- **Package Manager**: NPM

## 🏁 Getting Started

### Prerequisites

- Node.js (v18 or higher)
- npm

### Installation

1.  Clone the repository:
    ```bash
    git clone https://github.com/drLacheheb/overthewire-website.git
    cd overthewire-website
    ```

2.  Install dependencies:
    ```bash
    npm install
    ```

3.  Start the development server:
    ```bash
    npm run dev
    ```

    The site will be available at `http://localhost:4321`.

### Building for Production

To create a production build:

```bash
npm run build
```

The output will be in the `dist/` directory, ready for deployment.
